# JDFエディタ

JEOL 電子線描画装置 JBX-8100FS の描画スケジュールデータ準備システム(EXPRESS)向け
ジョブデックファイル(JDF)を、直観的な GUI 操作で作成・編集・入出力するデスクトップアプリケーションです。

## 動作環境

- Python 3.11 以上
- PySide6 6.6 以上

## インストールと起動

```bash
pip install -r requirements.txt
python main.py
```

## 画面構成(タブ)

| タブ | 機能 |
|---|---|
| 基本設定 | ジョブ名・材料サイズ(3/4インチ)・円形切り取り直径・PATH名・ヘッダコメント(JOB/PATHコマンド) |
| グローバルマーク | GLMPOS(P/Q/R/S座標)・GLMP(マーク幅/長さ)。座標プリセットの保存/選択/削除(JSON永続化)。ウエハ上のマーク配置模式図付き |
| チップ配列定義 | ARRAYの一覧管理(追加/編集/削除)。ネスティング階層をツリー表示(最大10階層、循環参照はバリデーションで防止)。配列プリセット保存/選択、起点座標の自動計算(中央揃え)モード、マップ太線グリッドの間隔設定 |
| チップ割付(マップ) | 配列点へのチップ割付(ASSIGN)をマップ上で実行。クリック=1点、ドラッグ=矩形一括、右クリック/消去モード=解除。ウエハ外周(SEMI M1準拠、オリフラ上側)表示、チップ色分け、ツールチップ(ショット(a,b)表示対応)、太線グリッド+ショット区間番号表示(番号サイズ 大/中/小)。割付対象コンボは番号+ファイル名+コメント併記。選択中の割付対象は太枠で強調。警告機能(変調テーブル未指定/同一パターンへの異なるテーブル混在を検出し警告文+赤枠表示、ON/OFF切替、無ラベル配列=デフォルトON・ラベル付き=デフォルトOFF)。右側に割付集計表(表示色/番号/チップ名/コメント/割付数、列の表示切替可、直接ASSIGN対象のみ) |
| LAYER設定 | LAYERごとに SCALE/EOS/SHOT/RESIST/STDCUR とチップ(Pコマンド)を設定。チップごとの展開式詳細パネルでファイル名・SPPRMを編集。レイヤーパラメータのプリセット、SPPRM一括入力、LAYER/チップの順番入れ替え(↑↓ボタン) |
| 変調テーブル | MODULATテーブルの作成/編集/削除((ショットランク,変調量)ペア)。ここで定義した名前がマップタブの選択肢に反映 |
| プレビュー・入出力 | 生成JDFのプレビュー、バリデーション警告表示、.jdf保存/インポート、プロジェクト(JSON)保存/読込 |

## 表示設定

メニューバーの「設定」から以下を変更できます(`~/.jdf_editor/settings.json` に永続化):

- **文字サイズ**: 大(13pt)/中(11pt)/小(9pt=従来のサイズ)
- **フォント**: システムにインストールされている可読性の高い日本語フォント(Noto Sans CJK JP、BIZ UDPGothic、Meiryo UI など)から選択可能

## 太線グリッドとショット(a,b)

チップ配列定義タブの配列編集欄で「太線グリッド」をONにすると、マップの外周左辺・上辺を1本目として、指定チップ数ごと(X/Y独立)に境界が太線で描画されます。X方向 a 番目と a+1 番目、Y方向 b 番目と b+1 番目の太線に挟まれた領域が「ショット(a,b)」で、区間番号がマップ外周のすぐ外側(上辺の外・左辺の外)に表示され、チップのツールチップにも「ショット(a,b)」が表示されます。デフォルトはOFF(全て細線)です。区間番号の文字サイズはマップタブの「番号サイズ」(大/中/小)で変更でき、`settings.json` に保存されます。

## 基本的な使い方

1. 「基本設定」で材料サイズなどを設定
2. 「グローバルマーク」で P/Q/R/S の座標を入力(よく使う組み合わせはプリセット保存)
3. 「チップ配列定義」で ARRAY を追加(ネスティングする配列にはラベル番号を付ける)
4. 「LAYER設定」でレイヤーとチップ(パターンデータファイル名)を登録
5. 「変調テーブル」でショットタイム変調テーブルを定義
6. 「チップ割付(マップ)」で配列定義を選び、チップとテーブルを選択してマップ上で割付
7. 「プレビュー・入出力」で内容を確認し .jdf を保存

既存の .jdf は「JDFインポート」で読み込めます(コメント行・行またぎ記述も解釈します)。
編集中の内容は「プロジェクト保存」で JSON(.jdfproj.json)に保存し、再読込できます。

## 出力JDFの仕様

- 構成: 共通部 → レイヤー部(複数可) → END
- 1コマンド1行(GLMP/EOS等も1行にまとめて出力)
- 同一チップ・同一変調テーブルの連続した割付は範囲指定 `(j-j',k-k')` に自動でまとめて出力
- パラメータ値域はフォーマット仕様書 5.2節(JBX-8100シリーズ制限値)に基づきバリデーション

### フォーマット(整形)仕様

生成される JDF は人間が読みやすいよう以下の通り整形されます(見た目のみの整形で、コマンドの語順・パラメータは変更しません)。

- **セクション区切り**: 各セクション(グローバルマーク / チップ配列 / パターン配列 / 各LAYER / END)の前に空行とセパレータ行(`;` + ハイフン50個)とセクション名コメントを挿入。JOB 行より前には装飾を置かないため、生成物を再インポートしてもヘッダコメントが変化しません(冪等)
- **タブ桁揃え**: ARRAY行・LAYER行・P行・MODULAT行のインラインコメントは、タブ幅8でカラム48以降の直近タブストップに揃えます(プレビューでもタブ幅8で表示)
- **字下げ**: ASSIGN行・SPPRM行は8スペース字下げ(AENDは字下げなし)
- 配列ブロック間には空行1行を挿入。無ラベル配列(チップ配列)とラベル付き配列(パターン配列)はセクションを分けますが、モデル内の配列順序は維持します

## ファイル構成

```
main.py              エントリポイント
jdf/                 JDFエンジン(GUI非依存)
  model.py           データモデル(JobDeck)
  generator.py       JDFテキスト生成(範囲自動まとめ含む)
  parser.py          JDFインポート(行またぎ・コメント対応)
  validation.py      値域バリデーション(仕様書5.2節)
gui/                 PySide6 GUI
  main_window.py     メインウィンドウ(7タブ + 設定メニュー)
  context.py         共有コンテキスト(AppContext)
  settings.py        文字サイズ・フォント設定の永続化/適用
  tab_basic.py       タブ1 基本設定
  tab_marks.py       タブ2 グローバルマーク
  tab_arrays.py      タブ3 チップ配列定義
  tab_map.py         タブ4 チップ割付マップ(QGraphicsView)
  tab_layers.py      タブ5 LAYER設定
  tab_modulat.py     タブ6 変調テーブル
  tab_preview.py     タブ7 プレビュー・入出力
tests/               自動テスト(pytest)
```

- `settings.json` — 文字サイズ・フォント
- `glmpos_presets.json` — GLMPOS プリセット
- `array_presets.json` — チップ配列プリセット
- `layer_presets.json` — レイヤーパラメータプリセット
